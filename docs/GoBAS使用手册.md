# GoBAS 使用手册

## Poc 源同步

本机安装 git 后，可以根据表单拉取 git 上的 POC 模板集。

拉到本地模板集后去重建立索引，数据量很大的话会比较慢，需耐心等待 15-30 分钟。如不需要这么多 POC，也可删除部分 `clone-templates` 目录下的 POC 模板，索引构建时间也会更快。全部入库约 19w+ POC。

> 注意：索引建立后不可删除 `clone-templates` 目录下的文件，否则会丢失 POC 模板。

## 自定义 POC

通过 nuclei 模板录入自定义 POC。

## 模板集管理

攻击测试时选取需要测试的 POC 加入模板集。

## 目标管理

可以添加 HTTP 目标以及 TCP 目标，且支持 IPv6 目标。

## 发起攻击

可以选择模板集扫描，也可以按规则自行选择 POC 扫描。目标选择后，可以选择直连或代理后扫描。

启动扫描后，会自动根据选择的 POC 是 HTTP 或 TCP 协议匹配目标。

## 扫描记录与结果

### 结果明细

- 可以看到每个 POC 的攻击情况、流量情况，以及系统判定结果。
- 支持根据请求包/返回包内容搜索关键字（方便快捷找到拦截特征）。
- 可以自行修改系统自动判定的结果，例如将 timeout 修改为 hit，可单独也可批量。

### 任务流量

快捷查看任务的流量记录，与结果明细类似，只可以查看单个 POC 的最后一个数据包的流量。

### 镜像连接

记录任务的全部流量，包含 fuzz 的 POC 模板会记录每一次的流量，方便回溯。

## 报告

支持 md、json、csv 三种导出格式。
